# Арт для главной страницы

Положите сюда изображение с именем `hero.webp` (подойдут также `hero.png`,
`hero.jpg`, `hero.avif`) — оно появится в карточке на главной странице и на
странице входа. Лучше всего смотрится вертикальная картинка с пропорциями
примерно 4:5 (например, 1200 × 1500).

Используйте только тот арт, на который у вас есть права: свой рисунок,
заказанный фан-арт или изображение с разрешением автора.

Если файла нет, сайт показывает фирменную эмблему MindClass.
