# Арт для главной страницы

Проще всего загрузить картинку через **Админку → Оформление**: там же
задаются подпись и кадрирование, а файл не нужно коммитить.

Второй способ — положить сюда изображение с именем `hero.webp` (подойдут
также `hero.png`, `hero.jpg`, `hero.avif`) и пересобрать сайт. Оно появится
в карточке на главной странице и на странице входа. Лучше всего смотрится
вертикальная картинка с пропорциями примерно 4:5 (например, 1200 × 1500).
Картинка из админки важнее этого файла.

Используйте только тот арт, на который у вас есть права: свой рисунок,
заказанный арт или изображение с разрешения автора.

Если арта нет, сайт показывает талисмана Лину.
