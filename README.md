# MindClass

Онлайн-читалка ранобэ «Добро пожаловать в класс превосходства»
(Youkoso Jitsuryoku Shijou Shugi no Kyoushitsu e). В каталоге — все тома
**первого** (1–11.5) и **второго** (1–12.5) года обучения.

Что есть на сайте:

- **Оформление по мотивам Амасавы Итики**: розовая палитра (сакура, малина,
  персик), падающие лепестки и мерцающие блики, «глитч» в заголовке, обложки
  томов с орнаментом-розеткой (у каждого тома свой), плавные переходы, тёмная
  тема и светлая «Белая комната». Без эмодзи и значков-смайликов.
- **Талисман сайта Лина** — собственный персонаж MindClass, нарисованный
  кодом: встречает на главной, на странице входа и на странице 404. Свою
  картинку с персонажем (например, с Итикой) можно загрузить в админке —
  см. раздел «Арт на главной».
- **Читалка**: 5 тем (ночь, белая комната, сепия, чёрная для OLED, как на
  сайте), 5 шрифтов, размер, интервалы, ширина колонки, выравнивание,
  красная строка. Полоса прогресса, оценка «сколько осталось», полноэкранный
  режим, оглавление, горячие клавиши. Иллюстрации открываются по клику.
- **Закладки** на любом абзаце, с заметками. У гостя хранятся в браузере,
  после входа переезжают в аккаунт и синхронизируются между устройствами.
- **Прогресс чтения**: сайт запоминает место в каждой главе и предлагает
  продолжить; прочитанные главы отмечаются в оглавлении и каталоге.
- **Вход и регистрация** (email + пароль, восстановление пароля). При
  регистрации выбирается ник, класс (A/B/C/D) и цвет аватара; на аватаре —
  первая буква ника.
- **Комментарии под каждым томом и каждой главой**: ответы, лайки,
  редактирование, спойлеры `||вот так||`, сортировка, модерация.
- **Поиск** (Ctrl + K или «/») по томам, названиям глав и по всему тексту
  загруженных глав.
- **Админ-панель**: импорт целого тома из EPUB, FB2, TXT/MD или HTML с
  предпросмотром, редактор глав, порядок перетаскиванием, черновики, роли
  пользователей, модерация комментариев, свой арт на главной.

> Текстов ранобэ в репозитории нет — они защищены авторским правом. Главы
> загружает администратор сайта через админ-панель. Размещайте только те
> тексты, на которые у вас есть права (например, переводы с разрешения
> переводчиков). Пока глав нет, работу читалки можно посмотреть на
> демо-странице `/demo`.

Сайт — самостоятельное приложение. Если он лежит в папке `mindclass/`
внутри другого репозитория, все команды ниже выполняйте из этой папки.

## Быстрый старт на своём компьютере

Нужен Node.js 20.19 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).

Без настроек сайт работает в **режиме витрины**: видны каталог, обложки,
демо-глава, закладки в браузере. Чтобы заработали вход, комментарии и главы
из базы — подключите Supabase (ниже).

## Подключение Supabase

Supabase — бесплатная облачная база данных со входом по email. Свой сервер
писать не нужно.

1. Создайте проект на [supabase.com](https://supabase.com). Лучше отдельный
   от трекера привычек, чтобы аккаунты читателей не смешивались с вашими.
2. В проекте откройте **SQL Editor → New query**, вставьте целиком файл
   [`supabase/schema.sql`](supabase/schema.sql) и нажмите **Run**. Скрипт
   создаст таблицы, правила доступа и хранилище для иллюстраций. Его можно
   безопасно запускать повторно.
3. **Authentication → URL Configuration**:
   - *Site URL* — адрес сайта, например `https://mindclass.vercel.app`;
   - в *Redirect URLs* добавьте `https://ваш-домен/**` и
     `http://localhost:5173/**`. Без этого ссылки из писем (подтверждение
     почты, сброс пароля) не вернут читателя на сайт.
4. **Authentication → Sign In / Providers → Email**: если выключить
   *Confirm email*, новые читатели попадут на сайт сразу после регистрации.
   Если оставить включённым, им придёт письмо со ссылкой. Встроенная почта
   Supabase отправляет мало писем в час; для живого сайта подключите свой
   SMTP в *Authentication → Emails*.
5. Скопируйте `.env.example` в `.env.local` и вставьте значения из
   **Project Settings → API Keys** (или кнопки **Connect**):

   ```
   VITE_SUPABASE_URL=https://xxxxxxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=ключ
   ```

   Подойдёт и старый *anon public key*, и новый *publishable key*
   (`sb_publishable_…`). Секретный ключ (*service_role* / *secret*) сюда
   **не** вставляйте.
6. Перезапустите `npm run dev`, зарегистрируйтесь на сайте и сделайте себя
   администратором в **SQL Editor**:

   ```sql
   update public.profiles set role = 'admin' where username = 'ВашНик';
   ```

   После этого в меню профиля появится пункт «Админка». Других
   администраторов и модераторов можно назначать прямо в админ-панели.

На бесплатном тарифе Supabase может приостановить проект, если им долго не
пользовались. Тогда его достаточно возобновить в панели Supabase.

## Публикация на Vercel

1. На [vercel.com](https://vercel.com): **Add New → Project** → выберите этот
   репозиторий.
2. Framework Vercel определит сам (Vite), команды сборки менять не нужно.
   Если сайт лежит в подпапке `mindclass/` другого репозитория, укажите её в
   **Root Directory**.
3. В **Environment Variables** добавьте `VITE_SUPABASE_URL` и
   `VITE_SUPABASE_ANON_KEY`.
4. Нажмите **Deploy**. Файл `vercel.json` уже настраивает маршруты, чтобы
   прямые ссылки на главы открывались без 404.
5. Добавьте полученный адрес в *Site URL* и *Redirect URLs* в Supabase
   (шаг 3 выше).

## Как загрузить главы

**Админка → Тома и главы** → выберите том → перетащите файл.

| Формат | Как определяются главы |
| --- | --- |
| **EPUB** | по оглавлению книги; если его нет — по заголовкам. Иллюстрации загружаются в хранилище автоматически. |
| **FB2**, **FB2.ZIP** | по секциям `<section>`; картинки тоже переносятся. |
| **TXT**, **MD** | по строкам-заголовкам: «Пролог», «Эпилог», «Интерлюдия», «Послесловие», «Глава 1…», «Глава IV…», «Глава первая…», а также `# Название`. Кодировки UTF-8 и Windows-1251. |
| **HTML** | по заголовкам `<h1>`/`<h2>`. |

Можно выбрать сразу несколько файлов (например, по одному на главу). Они
склеятся по порядку имён: `01`, `02`, … `10`.

Перед сохранением сайт покажет найденные главы. Названия можно поправить,
лишние куски (обложку, служебные страницы) — снять галочкой. Режимы:

- **Добавить в конец**: новые главы встают после существующих.
- **Заменить главы тома**: главы заменяются по порядку номеров, поэтому
  комментарии и закладки к ним сохраняются. Лишние старые главы удаляются.

Отдельную главу можно создать или поправить в редакторе («Новая глава» или
значок карандаша). В нём есть предпросмотр и загрузка иллюстраций.

### Разметка текста глав

| Что написать | Что получится |
| --- | --- |
| обычная строка | абзац |
| `***`, `* * *`, `◇◇◇`, `———` | разрыв сцены |
| `## Подзаголовок` | подзаголовок внутри главы |
| `> Текст` | врезка: переписка, записка, объявление (строки подряд объединяются) |
| `-> Текст <-` | текст по центру |
| `**жирный**`, `*курсив*` | выделение |
| `![подпись](https://…)` | иллюстрация |

HTML в тексте не выполняется: всё экранируется.

## Арт на главной

Карточка на главной странице и панель на странице входа могут показывать
вашу картинку — например, арт с Амасавой Итикой.

**Через админку** (проще всего): **Админка → Оформление** → перетащите
картинку (WEBP, PNG, JPG или AVIF до 8 МБ), напишите подпись и подвиньте
кадр ползунками. После «Сохранить» картинка сразу появится на сайте, а
кнопка «Убрать арт» вернёт талисмана. Лучше всего смотрится вертикальная
картинка примерно 4:5, от 900 px по короткой стороне. Файл хранится в
Supabase Storage (папка `site/` корзины `illustrations`), настройки — в
таблице `site_settings`. Если база создавалась по старой версии
`schema.sql`, запустите файл ещё раз: он добавит эту таблицу.

**Файлом в проекте**: положите картинку в `src/assets/art/` с именем
`hero.webp` (подойдут и `hero.png`, `hero.jpg`, `hero.avif`) и пересоберите
сайт. Картинка из админки важнее файла.

Рисунков персонажей ранобэ в проекте нет: они защищены авторским правом.
Используйте арт, на который у вас есть права: свой рисунок, заказанный арт
или изображение с разрешения автора. Пока арта нет, показывается Лина —
собственный талисман сайта ([`src/components/brand/Mascot.tsx`](src/components/brand/Mascot.tsx)).

Цвета темы задаются в начале [`src/index.css`](src/index.css): тёмная тема —
блок `[data-theme='dark']`, светлая — `[data-theme='light']`.

## Горячие клавиши читалки

| Клавиша | Действие |
| --- | --- |
| ← / → | предыдущая / следующая глава |
| B | закладка на абзац, который сейчас читаете |
| S | настройки текста |
| T | оглавление и закладки главы |
| F | полноэкранный режим |
| Ctrl + K или / | поиск (на любой странице) |

## Роли

- **Читатель** комментирует, ставит лайки и закладки.
- **Модератор** может удалять любые комментарии.
- **Администратор** управляет главами, назначает роли, модерирует.

Права проверяются в самой базе (Row Level Security), а не только в
интерфейсе.

## Как добавить третий год

Откройте [`src/data/catalog.ts`](src/data/catalog.ts) и добавьте ещё один
`makeYear(3, …)` со списком томов по образцу первых двух. Ключ тома
строится как `y3-v1`, `y3-v4.5` и т. д. Свою обложку можно положить в
`public/covers/` и указать в поле `cover` тома.

## Для разработки

```bash
npm run dev        # локальный сервер
npm test           # тесты (разметка, комментарии, импорт EPUB/FB2/TXT, арт)
npm run typecheck  # проверка типов
npm run build      # сборка в dist/
```

Стек: React 19, Vite, TypeScript, Tailwind CSS, Framer Motion, TanStack
Query, Zustand, Supabase (Postgres, Auth, Storage).

```
mindclass/
├── supabase/schema.sql      база: таблицы, права доступа, триггеры, поиск
├── src/data/                каталог томов, цитаты, демо-глава
├── src/api/                 запросы к Supabase
├── src/lib/importers/       импорт EPUB / FB2 / TXT
├── src/lib/markup.ts        разметка глав
├── src/components/          интерфейс: читалка, комментарии, обложки…
└── src/pages/               страницы и админ-панель
```
